# PokeVerse

A sleek and modern Pokémon database application with a stunning dark-themed interface. Explore and search through hundreds of Pokémon with detailed stats and information.

## Features

✨ **Modern Dark Theme** - Elegant dark interface with cyan accents for a sophisticated look

🔍 **Advanced Search** - Search Pokémon by name or ID in real-time

📊 **Detailed Stats** - View comprehensive Pokémon statistics including HP, Attack, Defense, and more

🎨 **Responsive Design** - Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices

✨ **Smooth Animations** - Beautiful staggered entrance animations and hover effects

⚡ **Fast Performance** - Optimized for quick loading and smooth interactions

## Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **API**: [PokéAPI](https://pokeapi.co/) - Free Pokémon API
- **Styling**: Custom CSS with glassmorphism effects

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for API calls)

### Installation

1. clone  git clone https://github.com/BATTI-CHANDAN-SINGH/MERN-STACK.git or  download the ZIP from the githuv 
2. Open `index.html` in your web browser
3. Start exploring PokeVerse!

## Usage

1. **Browse Pokémon**: The page loads with a grid of Pokémon cards
2. **Search**: Use the search bar to find Pokémon by name or ID
3. **View Details**: Click on any card to see detailed information
4. **Stats**: Each card displays key stats like HP, Attack, Defense, Speed, and more
